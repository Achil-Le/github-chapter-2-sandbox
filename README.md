# GitHub Chapter 2 - Sandbox 🚀-Platforme d'apprentissage

Bienvenue dans mon dépôt de type "bac à sable" ! 

## 📖 À propos
Ce dépôt est un espace d'expérimentation strictement dédié à la pratique et à l'apprentissage des concepts Git et GitHub. Il sert d'environnement sécurisé pour tester différentes commandes et workflows de développement sans affecter des projets en cours.

## 🎯 Objectifs
* Expérimenter la gestion des versions (commits, branches, fusions).
* Maîtriser la création et la gestion des requêtes d'extraction (Pull Requests).
* Pratiquer la résolution de conflits de fusion (merge conflicts).
* Structurer la documentation des projets informatiques avec Markdown.

## 🛠️ Outils utilisés
* **Git** : Système de contrôle de version.
* **GitHub** : Plateforme d'hébergement et de collaboration.
* **Markdown** : Formatage de texte pour la documentation.
